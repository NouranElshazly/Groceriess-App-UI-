# GreenMart 🥕🛒
A modern grocery shopping app for fresh produce built using Flutter. GreenMart provides a seamless experience for customers to browse and order fresh vegetables, fruits, and other produce items.

## 📦 Installation

1. **Clone the repository**
```bash
   git clone git@github.com:NouranElshazly/Green_Mart.git
   cd GreenMart
```

2. **Install dependencies**
```bash
   flutter pub get
```

3. **Run the app**
```bash
   flutter run
```

## 📋 Prerequisites
- Flutter SDK (latest stable version)
- Dart SDK
- Android Studio / VS Code with Flutter extensions
- An emulator or physical device for testing
